# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release of Aura.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0.0 | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in Aura, please report it privately rather than creating a public issue.

### How to Report
* Reach out privately on Telegram:
  * Direct Contact: https://t.me/duhitssaniket
* Alternatively, submit a private security advisory through GitHub:
  * https://github.com/aniketdubey1204-code/Aura/security/advisories
* Include:
  * Description of the vulnerability
  * Affected versions and components
  * Steps to reproduce or proof-of-concept
  * Potential impact assessment

### Response Timeline
* **Initial acknowledgment:** Within 48 hours.
* **Assessment & mitigation plan:** Within 5 business days.
* **Public disclosure:** Coordinated after a patched release is published.

Thank you for helping keep Aura secure for all users.
